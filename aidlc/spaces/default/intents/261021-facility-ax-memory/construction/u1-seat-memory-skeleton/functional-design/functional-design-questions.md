## 振る舞いの既定（手本の角の一覧から。owner が後で直せる）

- **割り当ての状態**: 共通基盤の取り決めのとおり、draining（引き継ぎ中）・期限切れ・closed の割り当ては、新しい書き込みにも読み出しにも使わない。共通基盤の確かめが返す理由（OC001〜OC011）を、Kusabi の失敗の形（取り決め C1 の errors）に写すだけで、意味を作り直さない（設計・実装の標準 S2）
- **共通基盤が入っていない DB**: 共通基盤の形の設定で、DB に共通基盤の置き場が無い時は「共通基盤が入っていない」と理由を返し、表を作らない
- **U1 にまだ無い道具**: 共通基盤の形で、U1 にまだ無い記録の道具（作業の状態・学び・置き換え・会話の取り込みなど）を呼ぶと、「共通基盤の形ではまだ使えない（後の単位で入る）」と理由を返す。単独の形や今の表に逃げない
- **単独の形**: 単独の形（手元の SQLite）の振る舞いは U1 で変えない
- **決定の記録**: 決定の文・理由（context）・札（tags）・目印（project）を保ち、書いた時点の所属範囲・主体・席・割り当て・世代の参照を付けて、後から書き換えない。有効な決定だけを回復の内容に入れる
- **持ち主の名前の扱い**: 共通基盤の形では、環境の `AGENT_MEMORY_AGENT_ID` を持ち主に使わない。値があっても読み書きの範囲を変えない
- **呼出しの記録**: 道具の名前・記録の ID・時刻・結果（成功か失敗の理由）だけを書き、決定の文・作業の名前・学びの題・資格情報を書かない
- **起動の口で DB に届かない時**: 席の起動を止めず、最初の文脈に「記憶に届かない」と出し、回復の内容は空にする（古い写しで補わない）
