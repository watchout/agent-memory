X. Other (please specify)

（arc の勧め: C。承認した意図の文書（Q12）は、成功の測り方を「担当交代と再起動の場面を決めた試験で取り出せる割合 100%」と決めている。分母はその試験の場面の記録で、C がこれに当たる。A は測り方を実際の記録まで広げる変更になり、B は結べない記録がある間 100% に届かない。結べなかった古い記録の件数は、C でも別に示す）
