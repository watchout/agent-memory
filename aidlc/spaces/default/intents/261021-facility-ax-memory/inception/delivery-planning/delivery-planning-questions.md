# 作る順の計画（Delivery Planning）— 計画の案と質問

これまでの段階の出力（要件・利用者の話・部品の一覧・作業の単位・単位の依存・取り決め・進め方）から、作る順の計画の案を出し、まだ決まっていない所だけを聞きます。

この段階の言葉: **Bolt**（ボルト）は、作る段（Construction）を 1 回通して、1 つ以上の作業の単位を「動く物」まで仕上げる一区切りのこと。**薄い一本**（walking skeleton）は、本当の機能を入れる前に、部品どうしが端から端までつながって動くことを確かめる最小の版のこと。

## 決まっていること（聞き直さない）

- 最初の Bolt は薄い一本（U1）。動くことを owner が確かめてから残りに進む（team.md の Walking Skeleton）
- その後は、いちばん不確かな所から作る。種類の違う席の間で同じ仕事の記憶を引き継ぐ所（P2 = U2）を先にする（範囲の段の決定 D-28）
- 成功の条件の場面の試験を、その場面を作る実装より先に書く（team.md の Testing Posture）
- 単位の細かさは 1 つの単位が PR 1〜2 本（作業の単位の段の Q1 = A）なので、1 つの Bolt = 1 つの単位にする
- 作る段は一つずつ順に進める（単位ごとに設計の段とコードを書く段を回し、確かめてから次へ。並べて作らない）。実装を受け持つ席は 1 つ（kusabi の席、D-30）
- 実装は停止（T102）が解けてから。Kusabi の順番は Shirube・AUN → Onza → Tsumama → Kusabi（D-20・D-32）
- 点数をつける式（WSJF など）は使わない。上の決まりで順が決まるため
